## 2. Interface changes are now in the game

The fixes from `Cyclops-UI-Improvements.html` are now built into Farshore. Before this they were only in a standalone mock-up. They were checked in the browser on desktop (1440×900) and phone (390×844) with the mock AI service: 23 automated checks pass on desktop and 22 on phone. The 268 project tests pass, one of them new.

| Finding | Change in the game |
| --- | --- |
| B1: explanation too dense | In-play panel shows the action first, then one short reason, e.g. "Your recent moves point to the Centre lane." The algorithm and full reasoning sit under "How it decided" and in AI Lab. |
| B2: feels like guessing | Forecast reads "Forecast 68% chance you are there when it lands. A prediction, not a sure hit." The last observed result appears separately under "Last result · observed". A throw that has landed leaves the headline. |
| B3: slow to locate | Panel is headed "Opponent plan". A three-lane cue marks your lane ("You") and the lane a locked boulder is aimed at. |
| B4/X1: recovery and labels | "Keep the previous strategy" is a full button beside "Prepare the rival again". The disabled start button names the same state as the panel, e.g. "The rival is not ready · Prepare the rival again to start". |
| Found during integration | "Cancel preparation" used to restart preparation immediately. It now stops and shows "No strategy prepared" until the player chooses. |

To show the panel as it was first tested, add `?ui=baseline` to the URL. `Evidence/In-game-after-fixes/01-before-panel-baseline.png` and `02-after-panel.png` show the same moment of the same seeded run. The screenshots used the mock AI ("mock-ai (test mode)" is visible in the header). They are real captures of the game, not schematics.
