Model integration

Llama 3.2 3B through local Ollama: Encounter ID, Easy/Normal/Hard and at most two numeric attempt summaries. Server derives habits and losses. Current engines retain zero-valued legacy timing and lane-duration fields. No name, voice or chat text. JSON with planId and focus. The model chooses one of two adaptive strategies. The game fixes the required focus. Server validates both and supplies an authored description.

Measured setup uses loopback Ollama. No third-party AI provider receives these requests. A hosted endpoint would receive the selected shore, difficulty, derived habits and win count. It would need a changed disclosure.
